# 🎮 Count Me Out

**Your score is your enemy.** A fast browser arcade game built for our final hackathon.

### ▶️ [Play it now](https://saardhakram.github.io/Count_On_Me-game/)

## How to play

1. **Eat the dots.** Glide around and collect the shiny yellow dots.
2. **Your score turns foe.** Every point spawns an angry number that chases you.
3. **Dodge the numbers.** One touch and it's game over.

## Features

- ⚡ **Dash:** a short, untouchable burst of speed, with a recharge ring
- 🔥 **Combos:** chain dots quickly; from x3, every dot is worth double
- 🎲 **Surprise events** every 10 points: *Speed Surge*, *Reverse* (flipped controls), *Lights Out* and *Number Rain*
- 🏆 **Leaderboard** with today's and all-time best scores per player
- 🌌 Neon visuals, sound effects and a live danger meter

## Built with

HTML, CSS and JavaScript in a single file, hosted on GitHub Pages. No libraries.

## Run locally

Download `index.html` and open it in any modern browser.
